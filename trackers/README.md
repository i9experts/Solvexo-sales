# Trackers

**`Solvexo_Seller_Pipeline_Tracker.xlsx`** is a blank template. Make a copy in your own drive and fill that in. Don't commit filled-in copies.

- **Leads:** one row per seller. Stage dates: First contact → Demo booked → Demo held → Store live → Paid. The cream cells are inputs; the rest are formulas.
- **Dashboard:** stage counts, conversion between stages, monthly value, sales cycle, overdue follow-ups, lost reasons. Filter by module in cell B3.
- **Settings:** edit the dropdown lists (modules, seller types, sources, lost reasons) here.

Row 5 is an example. Overwrite or delete it.
