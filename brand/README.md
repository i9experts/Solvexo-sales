# Solvexo Brand Kit

## Logo files

| File | Use it for |
|---|---|
| `logos/solvexo-logo-horizontal.png` | Default logo: website, decks, documents, social posts (transparent background) |
| `logos/solvexo-icon.png` | App icon, profile pictures, favicons, small spaces (transparent background) |
| `logos/solvexo-wordmark.png` | Where the icon already appears nearby, e.g. app headers (transparent background) |
| `logos/*-white-bg.jpg` | Same three logos on solid white, for tools that don't handle transparency (WhatsApp, some print shops) |
| `source/Solvexo_brand_logo.pdf` | Vector master. Send this to printers and designers. |
| `video/Solvexo_Logo_GrowthLaunch_9x16.mp4` | 7.5-second vertical logo animation (1080×1920) for Reels, TikTok, Stories and WhatsApp Status |

PNGs were rendered from the vector PDF at 600 dpi. For anything larger, export again from the PDF.

## Logo rules

- Keep clear space around the logo at least the height of the "o".
- Don't stretch, rotate, recolour, add shadows or outline the logo.
- On dark backgrounds, use the icon on its own, or ask the designer for a white-text wordmark (not yet in the kit).
- Minimum width: about 120 px on screen or 30 mm in print for the horizontal logo.
