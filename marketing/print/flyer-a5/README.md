# Main Flyer (A1): A5, double-sided

- **Source:** `flyer.html` (fonts in `fonts/`, Poppins + Noto Nastaliq Urdu, both open-licence). Rebuild the PDF with `node render.js` (needs Playwright).
- **Size:** A5 (148 × 210 mm) + 3 mm bleed on every side = 154 × 216 mm. Text kept 6 mm inside the trim.
- **QR:** points to `https://solvexo.store/?utm_source=flyer-a1&utm_medium=print`. Test it before every print run.
- **Fixes vs the old flyer:** "Live straight away" instead of "account ready within 24 hours"; "real sales reports" instead of "AI analytics"; prices only on the back, dated.
- **Printer notes:** 170 gsm gloss or matte art card, double-sided, trim to A5. The PDF is RGB; ask the printer to convert to CMYK and send a colour proof. Terracotta is `#D97757` (approx. C10 M62 Y68 K0; confirm on proof).
- **Before reprinting:** check the launch offer on solvexo.store/pricing; update or remove the offer box on the back if it has changed.
