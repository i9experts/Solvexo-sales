# SEO Titles & Meta Descriptions: solvexo.store

Written 22 Nov 2026 against the live site. Uses only claims from `product/approved-claims.md`.

**Rules used:** titles 60 characters or fewer (Google cuts longer ones off); descriptions 110–158 characters; main keyword first; brand at the end; a clear reason to click (7 days free, 0% commission on COD, etc.).

**Not used on purpose:** prices (the launch offer will change), "AI analytics" (the site says AI only writes product titles/descriptions), "mobile POS app" and "custom domain" (both on the roadmap).

## Developer handover

Each page needs these in its `<head>` (the site is a JavaScript app, so check they are in the **server-rendered HTML**, not only added by JavaScript. They are today, which is good):

```html
<title>…</title>
<meta name="description" content="…">
<meta property="og:title" content="…">
<meta property="og:description" content="…">
<link rel="canonical" href="https://www.solvexo.store/…">
```

## Other SEO fixes spotted

1. **Two current descriptions end in "…"** (Store Builder and POS): the text was cut off in the code. The new ones fix this.
2. **Five titles are over 60 characters** (Orders & Customers, Loyalty, Restaurants, Beauty, Creators) and get cut off in Google. Fixed above.
3. **The FAQ page** currently answers buyer questions (resetting passwords, damaged orders). Add seller questions people actually search: "how to make an online store in Pakistan", "is Solvexo free", "does Solvexo take commission on COD". Use the question regex in Search Console to find more.
4. **Add a Pakistan landing page** (e.g. `/pakistan` or `/online-store-pakistan`) for searches like "online store builder Pakistan" and "POS system Pakistan". The rest of the site is written for a global audience.
5. **Add an Urdu version of key pages** later: the site has Arabic but not Urdu, and many Pakistani sellers search in Roman Urdu or Urdu.
6. After updating, use **URL Inspection → Request indexing** in Search Console for the home, pricing and product pages, then compare CTR after 4 weeks.
